# someBackUps
Some packages will be put in here, only for back up.
测试方法（脚本实际执行）

工具：fio，direct=1，libaio

并发：numjobs=1 × iodepth=128（1x128）

落盘范围：size=50G，每项 runtime=3600s

预处理：16k 100% 全盘随机写（447GiB，约 30 分钟）

覆盖组合：块大小 1k / 3k / 4k / 8k / 64k × 读写比 0% / 70% / 100% read，共 15 个 case

判据：p99 / p99.99 / p99.9999 / p99.999999 任一超标即该项 FAIL
